# 检索评测报告：legacy(wp07-bigram) vs hybrid(r2-hybrid)（2026-10-31）

## 结论

**hybrid 检索全面优于 legacy，且逐题零退化**（24 题中 16 改善、8 持平、0 退化），
已作为 `/api/ask` 与 `/api/solve` 的默认检索器上线；`RETRIEVAL_MODE=legacy` 环境变量可随时回滚。

## 指标（24 题评测集，语料 832 单元，概念组 14 组）

| 指标 | legacy | hybrid | Δ |
|---|---|---|---|
| hit@8（top8 命中期望文章） | 33.3% | **95.8%** | +15 题 |
| MRR | 0.306 | **0.856** | +0.550 |
| 期望词在证据文本中的覆盖率 | 10.3% | **64.1%** | +53.8pp |

## 方法

- **hybrid = IDF 加权 bigram + 概念映射查询扩展（降权 0.5）+ 原邻段扩展/节标题增强**（`site/api/_retrieval.mjs`）
- IDF 按语料缓存（WeakMap）；概念映射 `site/data/concept-map.json`，所有扩展词均经全库词频验证真实存在
- 评测集 `pipeline/eval-retrieval-qset.json`：24 个**现代工作/生活口径**的问题（产品的真实使用方式），
  期望文章按语料主题人工判定，期望词经词频验证；复跑命令：
  `node pipeline/eval-retrieval.mjs`
- **守卫**：hybrid hit@8 低于 legacy 时退出码 1（CI/发布前可复跑）

## 为什么 legacy 差

legacy 的 raw bigram 计数依赖问题与原文**词面重叠**。评测集刻意用现代口径提问
（"跨部门没人落实""行业形势差不投入"），与 1928 年文本（"割据""统治阶级破裂"）词面几乎无交集，
因此漏召回严重——这正是"检索不足 ≠ 文集没有答案"假阴性的量化证明。
hybrid 靠两条腿解决：罕见 bigram 权重放大（IDF）+ 概念映射把"推进不动"接到"割据/巩固"等语料词汇。

## 已知缺口（如实记录）

1. **q09（负责人缺实权）legacy/hybrid 均未命中**："领导权"全库仅出现 2 次，证据本身稀薄——
   这类题的正解是语料扩容，不是继续调检索参数。
2. 概念映射是**人工策划**的词表，覆盖有限领域（工作/组织场景优先）；扩到新场景需同步扩映射并复跑本评测。
3. 评测集规模 24 题，属于**回归守卫**而非覆盖率证明；扩语料前需按同口径扩充题集。
4. hybrid 的期望词覆盖 64.1% 仍未到 80%+——剩余缺口主要是跨段语义关联（bigram 的天花板），
   若未来接入真正的语义向量（需新的 embedding 供应商），应以此评测框架对比验证后再替换。
