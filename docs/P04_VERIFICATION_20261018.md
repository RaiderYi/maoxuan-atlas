## P04.3 进度分开记录（✅ 关键验收点）

- 状态三档：`未开始` / `已打开 · 未标完成` / `已完成`
- **打开阅读不会自动算完成**：实测点读原文后 `s1` 变 `opened`，进度仍显示 `已完成 0/4 步`
- 只有点"我读完了本步"才写入 `doneAt`；可"撤销完成"
- 存储：`mx_topic_progress = {jgs:{steps:{s1:{openedAt,doneAt}}}}`

## P04.4 末步成果任务（✅）

- 空提交拦截：`还不能保存：结论还差 80 字（需至少 80 字，现 0 字）；还没有摘录原文段落（需至少 1 条依据）`，并明确列出缺口
- 无依据拦截：未摘录时显示"还没有摘录…没有依据的结论不会被当成完成"
