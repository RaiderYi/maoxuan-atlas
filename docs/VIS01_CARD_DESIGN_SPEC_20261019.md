## 3. 布局与间距

- 间距刻度：`4 / 8 / 12 / 16 / 24 / 32 / 48`（只允许这些值）
- 卡面比例：桌面 **3:4**，宽度 320—360px，高度自适应内容；手机满宽 − 32px，最大 420px
- 圆角：卡 `14px`、按钮 `12px`、内部分区 `10px`、肖像框 `8px`（肖像不切圆角过重，保留"印刷版画"的方正感）
- 边框：`1px solid var(--border)`；卡片阴影只允许一层极淡：`0 2px 14px rgba(30,27,23,.06)`
- 肖像占卡面 **45%—55%**，且**头部完整**（不得裁掉额头或下巴）；下方留 16px 与姓名相接

## 4. 卡面信息层级（首屏顺序，不可调换）

1. 小字"你的研读搭档"（`--ink-3`）
2. 肖像 → 姓名 → 主题
3. 三个方法关键词（横排，用 `·` 分隔，不加胶囊底色）
4. 一句基于**本次实际选择**的推荐解释
5. 主按钮「开始 3 分钟阅读」（朱砂实心）
6. 次按钮「保存人物卡」「生成分享图」（描边，`--ink-2`）

展开区（默认折叠）：为什么推荐（≤2 条，引用真实选项）、试一试（一个可完成动作）、
阅读任务（篇名/作者/指定段落/一句话写作提示）、资料依据与肖像说明、
多卡并列说明（"这次有几种方法同样突出" → 查看全部）。

**卡面禁止出现**：内部版本号、段落 ID、完整答题记录、长免责声明、"相似度百分比"。

## 5. 按钮层级

| 类型 | 样式 | 用途 |
|---|---|---|
| 主 | 朱砂实心、白字、`padding 12/20`、`min-height 44px` | 每屏最多 1 个 |
| 次 | 透明底 + `1px --border`、`--ink-2` 文字 | 保存/分享/查看全部 |
| 文字 | 无边框、下划线仅 hover | 返回、说明展开 |

- 触控目标 ≥ 44×44px
- 禁用态：`opacity .45` + `cursor: not-allowed`，**不用灰色伪装成可点**
- 焦点态：`outline: 2px solid var(--cinnabar); outline-offset: 2px`（键盘可见）

## 6. 断点与手机

| 断点 | 规则 |
|---|---|
| ≥ 1024px | 卡居中，最大 360px；画廊 3 列 |
| 768—1023px | 画廊 2 列 |
| < 768px | 单列；卡满宽 − 32px；肖像高度按 4:5 收窄 |
| 360 / 390 / 430px | 必须逐档实测：无横向滚动、姓名不换行成 1 字/行、按钮不重叠 |

200% 文本缩放：允许纵向增长，不允许横向溢出；关键词区可换行。

## 7. 动效（VIS08 用，本轮只定参数）

| 场景 | 时长 | 效果 |
|---|---|---|
| 选项选中 | 120ms | 边框变朱砂 + 勾选点淡入 |
| 揭卡 | 520ms | 透明度 0→1 + `translateY(8px)→0` |
| 收藏成功 | 180ms | 按钮文字换"已保存 ✓" + 1.8s 后复原 |
| 桌面悬停倾斜 | 220ms | ≤3°（`transform: rotate3d`），触屏禁用 |

`@media (prefers-reduced-motion: reduce)`：全部时长归零，只保留状态切换，不做位移与倾斜。

## 8. 资源预算

| 项 | 上限 | 当前 |
|---|---|---|
| 单张肖像 WebP | 250KB | 56—131KB（5 张） |
| 游戏页必要资源合计 | ~1MB | 待 VIS06 实测 |
| 分享 PNG | ~2MB | 待 VIS09 实测 |

加载策略：首屏卡肖像 `loading="eager"` + `fetchpriority="high"`；画廊其余 `loading="lazy"`；
`<img>` 必须带 `width/height` 防跳动；图片失败时显示姓名占位（`onerror` 切换），不显示破图。

## 9. 可访问性

- 正文对比度：`--ink-2` on `--paper` ≈ 8.9:1；辅色只做装饰，不承担信息
- 肖像 `alt` 文案由 `portraits.json` 的 `alt` 提供（含年代与"双色版画处理"说明）
- 键盘：Tab 顺序 = 肖像 → 姓名 → 主按钮 → 次按钮 → 展开区；不吃焦点
- 触屏不依赖 hover：所有悬停信息在点击/展开后同样可见
