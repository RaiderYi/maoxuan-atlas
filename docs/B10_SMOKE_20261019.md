第 7、8 条是本轮重点：旧实现限流 key 只有 `sid|ip`，删掉 Cookie 就拿到全新额度；现在纯 IP 桶独立计数，换 Cookie 无效。

## 2. 响应里的可核对字段（第 5 条实测）

```json
"governance": {
  "rateLimitScope": "global",
  "rateLimits": {
    "session": { "used": 1, "max": 5,  "remaining": 4,  "scope": "global" },
    "ip":      { "used": 1, "max": 12, "remaining": 11, "scope": "global" },
    "global":  { "used": 1, "max": 60, "remaining": 59, "scope": "global" }
  },
  "kvConfigured": true
}
```

429 的 body 形状是 `{ ok:false, error:{ code, message, detail:{ limitScope } } }`——第一版冒烟脚本读的是顶层 `limitScope`，所以显示 `None`；**是脚本读错字段，不是接口缺字段**，按 body 原文已核对无误（此处如实记录，避免后续误判）。
