# MaoXuan Atlas — Selected Works of Mao Tse-tung, Visualized

> An interactive reading atlas for the *Selected Works of Mao Tse-tung* (Vols. 1–5, 217 articles, 1925–1957).
> Terrain map · History progression · Timeline · Knowledge graph · Full-text search

**Live site**: https://aibigplayer.top

[中文说明 → README.md](README.md)

---

## What this is

This project structures all **217 articles** of the five-volume *Selected Works* and turns them into an explorable historical atlas. Every article is annotated with its **date, writing location, historical background (why it was written), related events, and cross-referenced articles**.

- Click a place on the terrain map to see the broader historical context of that location and every article written there.
- Drag the **History Progression** slider (or press play) to watch the route light up node by node: **Guangzhou → Changsha → Wuhan → Jinggangshan → Ruijin → Wayaobu → Bao'an → Yan'an → Xibaipo → Beiping**.

## Views

| View | Description |
|---|---|
| Atlas | Real shaded-relief basemap (NatGeo) + Chinese place labels + cinnabar route + per-place history cards + five-era filter |
| Chronicle | 1925–1957 horizontal timeline: per-year article histogram + volume-colored dots + click-to-expand year panels |
| Graph | Force-directed network of articles × historical events (colored by volume, click to read) |
| Reader | Context card (place / era / event / why-written) + full text + related-article links + prev/next navigation |
| Search | Title / background / event / place + full-text fuzzy search |

## Tech

Pure static site — no build step, no backend:

- **Leaflet** for the map (tiles self-hosted; zero runtime external dependencies)
- **ECharts** for the knowledge graph
- Vanilla HTML/CSS/JS, paper-and-ink aesthetic (xuan paper / cinnabar / ink)
- Deployed on Vercel (static config in `vercel.json`)

## Layout

```
site/            site source
  index.html     single-page entry (five views)
  app.js         all interaction logic
  assets/        leaflet / echarts / China GeoJSON (vendored)
  data/data.js   structured metadata for 217 articles
  data/texts/    [NOT committed] full texts, generated by the pipeline
pipeline/        data pipeline (requires your own PDF)
  extract.py     split the PDF into 217 full texts by TOC
  enrich.py      LLM-based per-article annotation (place/background/event/links)
  build_site.py  merge into data.js + texts/
  dl_tiles.py    pre-download China-area terrain tiles (Esri NatGeo, z4-z6)
data/            structured intermediate data (no full texts)
```

## Run / Reproduce

```bash
# Quick preview (no terrain tiles / no full texts until pipeline runs)
cd site && python -m http.server 8901

# Full reproduction (bring your own legally obtained PDF)
python pipeline/dl_tiles.py     # terrain tiles   → site/assets/tiles/
python pipeline/extract.py      # split texts     → data/articles_full.json + texts/
python pipeline/enrich.py       # LLM annotation  → data/enriched.jsonl (GLM API key required)
python pipeline/build_site.py   # build site data → site/data/
```
